# 🔍 Lost and Found Management System

A console-based Lost and Found Management System developed using Core Java. This application helps users report lost items,
submit found items, and manage records efficiently through a menu-driven interface.

---

## 🚀 Features

- Add lost item details
- Add found item details
- View all lost items
- View all found items
- Search item records
- Simple console-based interface
- Object-Oriented Programming concepts implementation

---

## 🛠️ Tech Stack

- Core Java
- OOP Concepts
- Collections Framework
- Java Console Application

---

## 📂 Project Structure

src
├── Main.java
├── LostItem.java
├── FoundItem.java
